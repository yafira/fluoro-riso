Riso-fy anything

Two inks, one sheet of paper. Load an image, then push the sliders to see how each print flaw changes the look. The same settings drive the page layout and the filter demo further down.

Press settings

Inks (they recolor this whole page)

Each ink is matched to the color channel it absorbs most, so pink reads the green channel and blue reads the red one. Images stay in your browser.

Layout built like a print

Every element is a flat ink layer. Overlaps use multiply, so pink over blue turns purple with no extra work. The headline above is one word printed twice, the second pass nudged by the misregistration slider.

Photos go through the canvas pipeline once. Everything else stays live text, so it remains sharp, selectable, and cheap to scroll.

Filter the live page

An SVG filter can riso-fy whatever the browser paints. It splits the block into two inks, thresholds each with noise, tints them, and multiplies them onto paper. It works on any markup, but it re-runs on every repaint, so it suits a hero or a section better than a whole site.
